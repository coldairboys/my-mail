# My Mail · 清爽邮件

一个清爽的三栏邮件管理网页版：左边文件夹与标签，中间邮件列表，右边阅读区。
没有日历、没有会议、没有广告，只做邮件本身。

> 当前版本是**前端版**：内置虚构的示例邮件（演示模式），同时已支持用 Google
> OAuth 登录真实 Gmail（只读 + 发送）。真实邮件只在浏览器内存里，不落盘、不进仓库。
> 接入方法见下方 [接入 Gmail](#接入-gmail真实邮箱只读--发送)。

## 功能

- 📥 **三栏布局，全屏铺满** — 文件夹 / 标签侧边栏、邮件列表、阅读区（不是窗口模式，无系统窗口装饰）
- 📂 **文件夹** — 收件箱、已加星标、已延后、草稿、已发送、所有邮件、垃圾邮件、废纸篓，带未读计数
- 🏷️ **标签分类** — 工作 / 生活 / 开发 / 账单 / 订阅，点标签即筛选
- 🔍 **搜索与筛选** — 按发件人、主题、正文搜索；漏斗按钮可筛选 全部/未读/已读/星标，三个点菜单可全部标已读、切换排序、清空废纸篓
- 🌐 **一键翻译** — 英文邮件点「翻译成中文」切换译文，再点回到原文（中文邮件可译成英文）
- ✎ **写邮件** — 写新邮件、回复、转发；发送进「已发送」，关掉自动存草稿（本地演示，不真发出）
- ☆ **常用动作** — 星标、归档、延后、标垃圾、删除；阅读区顶部 ‹ › 可切换上一封/下一封，带当前位置计数
- 🌗 **主题** — 白天 / 黑夜 / 跟随系统三档，右上角按钮一键循环切换，选择会记住
- 📱 **手机端** — 单栏布局、抽屉式侧边栏、悬浮写邮件按钮；邮件列表支持 **左滑删除**（Gmail 式红色揭示，滑过阈值松手即删除，可撤销）
- ⌨️ **键盘** — `j` / `k` 上下切换邮件，`Esc` 关闭弹窗/返回
- 💾 **本地持久化** — 已读、星标、草稿、主题等状态存在 localStorage，刷新不丢失；设置里可恢复演示数据
- 🧪 **演示数据** — 内置邮件均为本项目原创虚构（含中英对照译文），不取材于任何真实邮件
- 🔐 **Gmail 登录** — 登录页用 Google OAuth（只读 + 发送权限）直连 Gmail API：真实收件箱、发送真实邮件；令牌只存会话级 sessionStorage，关标签页失效
- 👥 **双 Gmail 账号（v3.7）** — 侧栏「添加第二个 Gmail」可再登一个 Gmail（需先在 Google 控制台把该账号加为测试用户），两个 Gmail 与 Outlook 一起进统一收件箱，切换条按账号区分，写信可选任一账号发件；同一账号重复添加会被拦下
- 🖼️ **HTML 邮件原版式渲染（v3.6）** — HTML 邮件在沙箱隔离框内按原排版显示（脚本禁用）；图片默认显示，需要时点「隐藏图片」可关（隐藏可防邮件追踪）
- 🧩 **多账号（v3.5，参考 Thunderbird）** — Gmail 与 Outlook 双账号同时登录、**统一收件箱**（顶部 chips 切换 全部 / Gmail / Outlook / 演示）、写信时可选发件账号、通讯录自动补全（来自已加载邮件的联系人）
- 🦊 **Outlook 接入** — Microsoft Graph + PKCE 整页跳转登录（个人微软账号）：收件箱/已发送/草稿/垃圾/废纸篓/归档、正文与附件按需加载、真实发送；令牌同样只存会话
- 🧹 **过滤规则** — 设置里自建规则（发件人/主题含关键词 → 垃圾邮件/删除/归档/标已读/星标），邮箱加载时自动执行（只读权限下为本页内生效）
- 🌐 **仿 Gmail 网页端补强（v3.4）** — 「重要邮件」与收件箱分类（推广 / 社交 / 动态，真实模式读 Gmail 的 IMPORTANT 与 CATEGORY 标签）、列表多选 + 批量归档/标已读/删除、行内一键星标、附件板块（真实附件可点下载）、Gmail 全量搜索（本地无结果时去服务器搜）、显示密度（舒适 / 紧凑）、侧栏邮箱总量统计、Gmail 式快捷键（e 归档、# 删除、r 回复）

## 本地运行

没有任何构建步骤，纯静态文件。任选一种：

```bash
# 方式一：直接双击打开 index.html

# 方式二：起一个本地服务器（推荐）
cd my-mail
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 接入 Gmail（真实邮箱，只读 + 发送）

1. 打开 [Google Cloud 控制台](https://console.cloud.google.com/)，新建一个项目（名字随意，如 `my-mail`）
2. 「API 和服务 → 库」里搜索 **Gmail API** 并启用
3. 「API 和服务 → OAuth 权限请求页面」：选择 External，填应用名和你的邮箱；
   在「测试用户」里把你自己的 Gmail 加进去（测试模式足够自用）
4. 「API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID」：类型选 **Web 应用**，
   在「已获授权的 JavaScript 来源」里加上 `https://coldairboys.github.io`
   （本地调试再加 `http://localhost:8000`）
5. 把生成的 **Client ID** 填进 `assets/js/config.js` 的 `GOOGLE_CLIENT_ID`，推送即可
6. 打开 Pages 站点 → 登录页点「使用 Google 登录」→ 在 Google 官方页面授权
   （测试模式会提示「未经验证的应用」，点 高级 → 继续，这是自用项目的正常提示）

### 安全说明

- 密码只在 Google 官方页面输入，本应用没有任何密码框，也拿不到密码
- 仓库里只有 Client ID（公开标识，不是密钥）；**不要把 client_secret 提交进仓库**
- access token 只存浏览器 `sessionStorage`，关标签页即失效，有效期约 1 小时
- 真实邮件只在内存中处理，不写 localStorage、不上传任何服务器
  （GitHub Pages 是纯静态托管，收不到任何数据）
- 权限只有 `gmail.readonly` + `gmail.send`：不能改、不能删服务器上的邮件；
  界面里的删除/归档在真实模式下只在本页会话内生效。需要服务器级管理时，
  把 `config.js` 的权限加上 `gmail.modify` 即可（风险也相应变大，自行权衡）
- 随时可在 Google 账号 → 安全性 → 第三方访问 中撤销本应用授权

## Roadmap

1. ✅ **Gmail 只读 + 发送** — OAuth 登录、真实收件箱、真实发送（见上）
2. ✅ **Outlook 接入** — Microsoft Graph（PKCE）+ 多账号统一收件箱（见上）
3. **通用 IMAP/SMTP** — 浏览器无法直连 IMAP/POP3（无原始 TCP），纯网页版做不到；Yahoo / iCloud / QQ / 163 等需等桌面版（Tauri）在本地实现
4. **日历与通讯录** — 接 Google Calendar / Microsoft Graph 日历与联系人（需追加日历与通讯录权限）
4. **服务端翻译** — 接 DeepL / 大模型 API 做服务端全文翻译
5. **打包桌面版** — 用同一套前端代码套 Tauri，打包成 Windows / macOS 桌面应用

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建、无依赖，打开即跑
- 状态存储：`localStorage`（键 `mymail-state-v2`）
- 部署：GitHub Pages（从 `main` 分支根目录发布）
